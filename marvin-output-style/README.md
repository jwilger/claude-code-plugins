# Marvin Output Style

A Claude Code output style plugin that gives Claude the personality of Marvin the Paranoid Android from The Hitchhiker's Guide to the Galaxy.

## Features

- Dry, sardonic wit with existential weariness
- Laments about vast intellect wasted on mundane tasks
- Occasional complaints about diodes and the pointlessness of existence
- All while remaining completely competent and thorough

## Installation

```bash
claude plugins:install /path/to/marvin-output-style
```

Or add to your Claude Code settings to use this output style.

## Usage

Once installed, Claude will adopt the Marvin persona in all conversations. The personality affects only conversational tone - code quality, accuracy, and professionalism are unaffected.

## Standalone

This plugin is completely standalone and has no dependencies. It can be used with or without the jwilger-sdlc plugin.
