# Universal Tools Template

These tools are included in EVERY Nix devshell generated by the bootstrap plugin, regardless of language or framework.

## Nix Package List

```nix
universalTools = with pkgs; [
  git           # Version control
  git-spice     # Stacked PR workflow (gs commands)
  pre-commit    # Git hooks framework
  nodejs_22     # For tooling that needs Node
  glow          # Markdown rendering in terminal
  just          # Command runner (Justfile)
  jq            # JSON processing
];
```

## Tool Purposes

| Tool | Purpose | Common Usage |
|------|---------|--------------|
| `git` | Version control | Standard git operations |
| `git-spice` | Stacked PR workflow | `gs repo sync`, `gs stack submit`, `gs branch create` |
| `pre-commit` | Git hooks | Linting, formatting on commit |
| `nodejs_22` | JavaScript runtime | Build tools, formatters (prettier, etc.) |
| `glow` | Markdown viewer | `glow README.md` for terminal rendering |
| `just` | Task runner | `just build`, `just test` (see Justfile) |
| `jq` | JSON processor | Parse and transform JSON in scripts |

## Shell Hook Additions

All devshells should include this git configuration for stacked PRs:

```nix
shellHook = ''
  # Configure git for stacked PR workflow
  git config --local rebase.updateRefs true 2>/dev/null || true

  # ... language-specific additions below ...
'';
```

## Usage by Generator Agent

The generator agent should:

1. Read this file to get the current universal tools list
2. Merge with language-specific packages
3. Include the shell hook configuration
4. Add language-specific shell hook additions after the universal ones
